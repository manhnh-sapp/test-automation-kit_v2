# Core Rules

> Bản digest non-negotiable cho agent. **Rule canonical đầy đủ: [`RULE_GLOBAL.md`](../../RULE_GLOBAL.md)** — khi mâu thuẫn, theo `RULE_GLOBAL.md`.

Áp dụng cho Phase 1, Phase 2, Re-run, Partial Rerun.

- **Scope**: `PROJECT_OUTPUT_DIR` + `TASK_KEY` bắt buộc; output ở `<PROJECT_OUTPUT_DIR>/tasks/<TASK_KEY>/`. Không suy `TASK_KEY` từ `.env`/context cũ. Chạy song song cùng `TASK_KEY` → bắt buộc `RUN_ID`. Echo scope trước khi ghi file/chạy command.
- **Phase-separated**: mỗi phase đọc lại artifact canonical trong task folder, không dựa context hội thoại cũ.
- **Nguồn testcase**: Excel canonical là source of truth khi **gen/publish** (Phase 1: sinh Excel → QA xác nhận → step riêng Auto Publish Jira lên Xray). **Phase 2 execute MẶC ĐỊNH lấy nguồn từ Xray** (`TESTCASE_SOURCE=xray`: kéo về canonical local `test-cases/from-xray/*.xlsx` rồi execute từ đó); `TESTCASE_SOURCE=excel` (opt-out) dùng `test-cases/*.xlsx`. Dù nguồn nào, execute đọc file canonical LOCAL — không gọi Jira/Xray cho từng case.
- **Parallel safety**: không sửa `.env`/shared helper/`tests/support/**` khi story khác đang chạy; automation mới ưu tiên `<TASK_OUTPUT_DIR>/automation/`; ghi `tests/fe|api/` phải namespace theo `TASK_KEY`.
- **Security**: không ghi/commit secret (token, password, cookie, API key, service-account JSON); sanitize evidence/report. Evidence phải **mask PII khách** (email, SĐT, họ tên, địa chỉ, mã định danh — kể cả trong `<input>`); artifact/report/Jira không được để lộ PII khách.
- **Automation quality**: test độc lập, có setup/cleanup; assertion thật; không xoá assertion hoặc đổi expected để pass; không hardcode dữ liệu task-specific vào template chung; test data unique + rollback được.
- **DB access — chỉ UAT read-only**: workflow chuẩn không connect DB. Ngoại lệ DUY NHẤT: read-only verify/chẩn đoán trên **UAT DB** qua guarded client `tests/support/setup/db/uatPgClient.ts` (read-only: chỉ SELECT). Chỉ cấu hình credential kho UAT (`LIB_MASTER_DB_*`) — kho UAT/PROD tách biệt; vẫn cấm `TEST_DB_*`/`TEST_DATABASE_URL`/`DATABASE_URL`/`PG*` và import `pg` ngoài client đó. Precondition (DỰNG state) chỉ qua UI/API/factory/hook/fixture — KHÔNG dựng bằng DB; thiếu capability thì `BLOCKED_SETUP`/`SKIP_SETUP`/manual. DB không phải evidence Jira.
- **Execution discipline (chạy thông suốt)**: mỗi lượt **batch NHIỀU case** (gom vào ÍT script toàn diện, case độc lập chạy song song) — CẤM "mỗi case 1 script/1 vòng rồi dừng-báo". **KHÔNG mặc định TODO/SKIP khi chưa thử**: dùng HẾT fixture/Deal/account đã cấp; case negative → tự tạo input (vd ID không tồn tại); drive thật rồi mới kết luận; chỉ TODO/BLOCKED khi **chặn thật** (capability/sandbox/account/scope) kèm **lý do cụ thể + điều kiện chạy được**. **KHÔNG hỏi lắt nhắt** — việc trong quyền hạn thì làm luôn; buộc hỏi thì **gom hết vào 1 lần**. Báo cáo **gộp, ít vòng, nhiều kết quả/lượt**. (Đầy đủ: RULE_GLOBAL §"Execution Discipline".)
- **Evidence (bắt buộc)**: MỌI case đã execute (PASS **và** FAIL) + MỌI step phải có evidence là **ảnh (`.png/.jpg/.jpeg/.webp`) hoặc video (`.mp4/.webm`)**. CẤM `.json/.md/.txt/.log/.html/.csv/trace.zip` hay file dữ liệu thô làm evidence (cần chứng minh data → chụp màn hiển thị data). Ảnh phải **highlight đúng element** đang kiểm, **mask PII khách**, và **đúng màn** (không 404/blank/loading dở/sai bước). Case phức tạp (cổng ngoài, async, multi-screen, iframe/upload) → **quay video**. Mỗi case dùng ảnh của chính nó, không placeholder/mượn. Lưu `test-results/artifacts/<TC_ID>/`. Dùng `scripts/utils/evidence_recorder.js`. (Đầy đủ: RULE_GLOBAL §"Evidence — Quy chuẩn bắt buộc".)
- **Comment kết quả (Test Run)**: gọn 1–2 câu, KHÔNG dán debug (`key=value`, dump state `A→A`, regex, `val="…"`, `match=true`), KHÔNG prefix trạng thái (`[PASS]/[Positive]/[Negative]` — đã có badge; kit tự tag SKIP/BLOCKED), caveat xuống dòng `Lưu ý:`, số/tiền dạng người đọc (`6.000.000đ`), không placeholder `Xem xxx.json`. (Đầy đủ: RULE_GLOBAL §"Comment kết quả".)
- **Reporting**: tiếng Việt có dấu UTF-8; FAIL ghi step/expected/actual/error + evidence bước lỗi; SKIP ghi TC ID + lý do + khả năng fix.
- **Setup/precondition**: setup precondition theo Setup Strategy contract (PRE-NN) qua capability an toàn; không log Jira cho `setup_failure`/`BLOCKED_SETUP`/`SKIP_SETUP`.
- **Jira bug gate**: chỉ log Jira khi fail đã xác nhận là **product/API bug** và đã **rerun đủ để loại flaky/setup**; KHÔNG log khi case `SKIP` hoặc fail do prompt/test/setup/data/env/dependency. Jira attachment chỉ ảnh/video.
- **Push Xray execution (Phase 2 QA-gated)**: khi cycle conclusive, chạy `--dry-run` trình preview cho QA → **chỉ `--write` sau khi QA duyệt**; run toàn `TO DO` (0 PASSED/FAILED) không tạo execution rác. Re-run tự tạo (không cần QA).
- **Cleanup**: dọn file debug tạm; không xoá output/evidence/report/file user tạo nếu chưa được phép.
